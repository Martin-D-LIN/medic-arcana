# 醫療魔導戰紀 MEDIC ARCANA

GitHub Pages 公開遊戲首頁，連結至 [Larch 遊戲](https://larch.ink/play/wOnTkJGDdF_Mupg4MGYDLBbm_21LYGQ3wnHWNw)。本專案不包含遊戲原始碼。

## 部署

1. 在 GitHub 建立公開儲存庫 `medic-arcana`。
2. 將 `index.html`、`cover.png`、`.nojekyll` 上傳到 `main` 分支根目錄。
3. 到 Settings → Pages → Build and deployment，選擇 Deploy from a branch、`main`、`/(root)`，按 Save。
4. 網站網址通常為 `https://你的帳號.github.io/medic-arcana/`。

請確保你擁有封面圖及遊戲素材的公開使用權。網站的開始遊戲按鈕會開啟 Larch。
